# SHFD Custom Cards 0.6.0 Beta 1

Prepared release notes for candidate tag `v0.6.0-beta.1`. This file does not create or publish a GitHub release.

## Highlights

- New SHFD Markdown Table Card for entity states, attributes, Jinja templates and text.
- Visual editor with shared display defaults and column/cell exceptions.
- Automatic or fixed column widths, single-line/multiline text and row spacing.
- Optional entity-state translation, units, decimals and alignment.
- State/range-based colors and icons, including cell background fills.
- Rule transfer to multiple visible cells without copying data sources.
- Global undo/redo and safeguards for replacement/deletion.
- Collection loader integration and a compact picker preview with clearly identified static example data.
- English/German documentation and labeled preview images.

Existing Room Card and FreshAirIQ runtime/picker files are unchanged from stable `v0.5.0`. The collection loader now also loads the Markdown Table picker.

## Installation and beta testing

Install all JavaScript files from this version's `dist/` directory together. Register only `ha-card-collection.js` as a JavaScript Module; do not register the individual cards/pickers as additional resources. Preserve HACS cache parameters; for manual installs update the resource version and reload the complete browser page.

Back up dashboard configuration and the current files before testing. Do not mix files from different releases. A rollback must restore the matching stable collection files together.

See the [collection README](../../README.md), [English table guide](../markdown-table-card.md) or [German table guide](../de/markdown-table-card.md).

## Validation and known limitations

This is a beta candidate, not a production certification. Before publication:

- Require successful HACS validation and the JavaScript/package/documentation checks.
- Test a fresh collection installation and picker preview in Home Assistant.
- Test existing Room Card and FreshAirIQ cards after the loader update.
- Test real entities, Jinja connections, translation, themes and native icon selection.
- Test narrow multiline cells, rule transfer, undo/redo, keyboard/touch and a full-page reload.

Earlier simulated DOM/backend tests are not a substitute for these real-browser checks. Picker examples are static, not live sensor measurements. Unit thresholds are not converted automatically; choose sensible rules.

The proposed package version is `v0.6.0-beta.1`; the Markdown component currently reports its independent development version `0.11.0-dev`. Preview behavior is supplied by its picker module. Historical tags, stable releases and runtime files are not changed by this preparation.

Publish, after separate approval, as a GitHub pre-release targeting the exact final checked feature-branch commit. Do not merge into main or mark a stable/latest release as part of this beta preparation.
