## Changes since Beta 1

- All card-documentation links in the main README are now absolute links to this beta tag, preventing HACS from resolving them against the older stable version.
- Updated documentation availability information for beta installations.
- Release notes use absolute documentation links and contain no internal preparation instructions.

The seven JavaScript files, including all cards, pickers and the collection loader, are unchanged from `v0.6.0-beta.1`. This release does not introduce runtime changes.

## Installation and testing

Select `v0.6.0-beta.2` explicitly when downloading through HACS. For manual installation, keep all JavaScript files from the same version together and register only `ha-card-collection.js` as a JavaScript Module. Reload the complete browser page after updating.

Back up your dashboard configuration and current files before testing. This remains a pre-release: verify picker previews, real entity/template values, state translation, formatting, rule transfer and existing Room/FreshAirIQ cards locally.

Existing stable releases and the Beta 1 tag remain unchanged.
